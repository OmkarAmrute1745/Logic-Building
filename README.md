# Logic Building

A collection of programming assignments and logic-building problems in C, C++, and Java, organized by topic for practice, learning, and interview preparation.

## Repository Structure

- `01-Assignments/` — programming assignments
  - C — Assignments 01–30
  - Java — Assignments 31–45
  - C++ — Assignments 46–48
- `02-Logic-Building/` — topic-wise programming practice
  - C
  - C++
  - Java
  - Special Topics

Projects are intentionally maintained in a separate repository.

## Languages

- C
- C++
- Java

## Commit Convention

- `NEW:` — add a new program, assignment, or topic
- `FIX:` — fix an existing program
- `OPT:` — improve existing code, structure, or documentation
